# TUess - TUI Chess
What is TUess? TUess is an open-source project built by EshanCreative MY Group designed to run at any platform. TUess uses simple and lightweight modules of Python to
make all laptop suitable on running it. 

# Speciality
The speciality of TUess is that it work with mouse interaction, have sound, and have flip board option. While it does not have online playing nor Ai battle, it is 1st ever
TUI Chess build using Textual and python-chess module that have mouse interaction and unicode usage of Chess symbols
